FLARE

Fractal Language for Autonomous Recursive Expansion

A language for multi-model AI prompting — query several models at once and post-process the responses: vote, summarize, combine, diff, expand, filter.

Browser-only No backend required Powered by Pollinations.ai

> FLARE syntax

{ flare model:openai,mistral temp:0.7 vote `Write a haiku about AI` }
vote — pick the best sum — summarize comb — combine diff — compare exp — expand filter — refine
